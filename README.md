# NixOS Hyprland — ThinkPad Z16 Gen 1

Standalone NixOS + Hyprland Flake for Ryzen 9 PRO 6950H, Radeon 680M + RX 6500M, 32 GB RAM, 1 TB SSD and OLED touchscreen.

Use Radeon 680M for everyday desktop use and RX 6500M selectively. AC power profile: Performance when available; battery: Power Saver when available. OLED guidance: moderate battery brightness, dark UI and screen blanking.

Before installing, generate hardware-configuration.nix and carefully review bootloader settings to preserve Windows 11 dual boot. This configuration is not yet evaluated or tested on the physical laptop.
